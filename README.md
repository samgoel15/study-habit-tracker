# Study Habit Tracker

A web-based Study Habit Tracker designed to help students organize their study tasks, track completion, and visualize their study progress through an interactive interface.

## Features

- **Task Management:** Add study tasks and specify the duration for each task.
- **Task Completion Tracking:** Mark tasks as completed using checkboxes.
- **Calendar View:** View daily progress through a calendar interface.
- **Progress Visualization:** Display study task completion data using charts.
- **Browser Storage:** Store task data locally using the browser's localStorage.
- **Navigation:** Access different pages, including the tracker, graph, welcome, and help pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser localStorage

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/samgoel15/study-habit-tracker.git
```

### 2. Open the Project

Navigate to the downloaded project folder.

### 3. Run the Application

Open `study-habit-tracker.html` in a web browser to access the main tracker.

No Python environment or backend server is required for this basic setup.

**Note:** Chart.js and some styling resources are loaded from external CDNs, so an internet connection may be needed for those resources to work.

## How It Works

1. Enter a study task and its duration.
2. Add the task to your list.
3. Mark tasks as completed to track your daily progress.
4. Use the calendar to view completion status.
5. View the graph page to see a chart of task completion.
